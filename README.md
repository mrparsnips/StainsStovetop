# Stain's Stovetop

A 4-burner coal/charcoal stovetop for [Vintage Story](https://www.vintagestory.at/) with vanilla firepit-style cooking.

## Features

- Shared firebox (charcoal / brown coal / black coal)
- Four burners; place pots in-world and cook with the firepit UI
- Uses the vanilla cooking pipeline (`BlockCookingContainer.DoSmelt`) so xSkills cooking XP applies
- Works standalone; when [Kevin's Furniture](https://mods.vintagestory.at/kevinsfurniture) is present, replaces that stove's cooking behavior

## Install

Drop `stainsstovetop_<version>.zip` into your `Mods` folder (do not unzip).
